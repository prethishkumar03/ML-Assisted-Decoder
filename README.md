# ML-Assisted-Decoder
Machine-learning-assisted decoding of the surface code using Logistic Regression, MLP and MWPM.

## Project Overview

This project investigates the application of machine learning techniques to quantum error correction, focusing on decoding the surface code.

The objective is to study whether machine-learning-based decoders can identify logical errors from measured error syndromes and compare their performance with conventional decoding approaches.

## Methods

The project explores the following decoding approaches:

- Minimum Weight Perfect Matching (MWPM)
- Logistic Regression
- Balanced Logistic Regression
- Multi-Layer Perceptron (MLP)

## Research Objectives

1. Generate surface-code error syndromes.
2. Train machine-learning models for syndrome decoding.
3. Compare ML-based decoding with conventional MWPM.
4. Evaluate logical error rates and classification performance.
5. Investigate decoder performance under different noise probabilities.

## Current Status

This project is under development. Current work focuses on benchmarking machine-learning-based decoders against MWPM and investigating generalisation, code-distance scaling, and computational performance.
